# Design de projet - les 4 phases

> Schéma trouvé par Quentin, utile pour expliciter la méthodologie de conception d'Anacoluthe (soutenance BPJEPS, présentations).

## Les 4 phases

### 1. ANALYSER
- Poser les bonnes questions
- Faire dialoguer les acteurs
- Repérer les angles morts
- Rendre lisible

### 2. EXPLORER
- Ouvrir de nouvelles pistes
- Donner forme pour comparer
- Forcer le détour
- Apporter des références

### 3. DÉVELOPPER / TESTER
- Modéliser pour ajuster
- Questionner les retours
- Interroger les choix
- Préciser la solution

### 4. LANCER / PRÉSENTER
- Structurer le récit
- Accompagner la présentation
- Anticiper les objections
- Clarifier le propos

## Lecture visuelle

Le diagramme fil de fer traduit le processus en une ligne qui évolue horizontalement :

- **Écheveau noué** (analyse) : complexité initiale, confusion du départ
- **Branches divergentes avec nœuds** (exploration) : divergence, pistes multiples
- **Boucles de retour** (développement/test) : itération, feedback, raffinement
- **Trait qui se tend vers l'avant** (lancement) : chemin clair, projection

## Mapping avec Anacoluthe

| Phase | Application Anacoluthe |
|---|---|
| **Analyser** | Diagnostic pédagogique initial, angles morts du dispositif existant |
| **Explorer** | Itérations V1→V3, comparaison des formes de cartes |
| **Développer / Tester** | Retours stagiaires, modélisation site + exports PDF, ajustements |
| **Lancer / Présenter** | Soutenance BPJEPS, essaimage CC-BY-NC-SA, communauté de référents |
